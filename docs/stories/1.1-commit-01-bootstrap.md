## User Story

**Como** equipe de desenvolvimento,
**Quero** uma base Maven executável com Java 21, Spring Boot 3.x, observabilidade básica, OpenAPI e testes locais,
**Para** iniciar a implementação dos requisitos de Organização de Recursos com uma fundação reproduzível.

## Objetivo e escopo

Implementar exclusivamente o Commit 01 - Esqueleto e execução local. A aplicação deve compilar, iniciar com o perfil `local`, responder ao health check e disponibilizar Swagger UI sem depender de um PostgreSQL existente.

Não fazem parte desta story: schema, migrations, `docker-compose.yml`, entidades, reservas, auditoria funcional, login, JWT, BCrypt, autorização por perfil, CI, JaCoCo, WireMock, Testcontainers ou interface de negócio.

## Acceptance Criteria

1. O repositório permanece na branch `develop`, sem commit, push ou alteração de branch.
2. Existe um projeto Maven com Java 21 e Spring Boot 3.x, contendo dependências para Web, Validation, Data JPA, PostgreSQL, Flyway, Security, Actuator, springdoc OpenAPI e JUnit 5.
3. O Maven Wrapper (`mvnw`, `mvnw.cmd` e `.mvn/`) permite executar `clean verify` sem Maven global instalado.
4. `application.yml` possui os perfis `local` e `test`; a configuração temporária desabilita a inicialização de JPA/Flyway sem banco e está documentada para remoção no Commit 02.
5. A estrutura modular de pacotes contém `auth`, `resource`, `reservation`, `approval`, `maintenance`, `usage`, `audit`, `notification`, `report` e `shared`.
6. A aplicação possui classe principal Spring Boot, endpoint `/actuator/health` com HTTP 200 e Swagger UI/OpenAPI acessível.
7. Não há credenciais reais, `.env` versionado ou JWT implementado; `.gitignore` e `.env.example` preservam as configurações AIOX.
8. `docs/adr/0001-stack.md` registra D1-D8 e pendências; `docs/quality/defects.md` é iniciado; README é complementado sem apagar a documentação existente.
9. Existe teste automatizado mínimo cobrindo a inicialização local/teste, health check e disponibilidade da documentação OpenAPI.
10. A validação registra Java 21, `clean verify`, execução local, health, Swagger, Git status, compilação e compatibilidade AIOX; comandos npm são tentados e reportados quando não aplicáveis ao projeto Maven.

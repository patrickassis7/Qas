# Story 1.4: Commit 04 - Pipeline CI e qualidade

**Epic:** Organização de Recursos - Base executável
**Story ID:** 1.4
**Sprint:** Commit 04
**Priority:** High
**Status:** Review
**Type:** DevOps / Quality

## User Story

**Como** equipe de desenvolvimento, **quero** validar cada Pull Request com Java 21, Maven, PostgreSQL via Testcontainers e relatórios de cobertura, **para** detectar regressões antes da integração.

## Escopo e decisões

- Workflow GitHub Actions em PRs destinados a `main` e `develop`, com permissões mínimas e actions oficiais fixadas por SHA.
- Java 21 Eclipse Temurin em runner Linux hospedado; cache Maven e execução do Maven Wrapper.
- Testcontainers inicia PostgreSQL real durante os testes; não usar banco substituto.
- JaCoCo gera relatórios XML e HTML no ciclo `verify`. Metas de 80% de linhas e 70% de branches são informativas neste commit; a obrigatoriedade fica para o Commit 14.
- SonarScanner for Maven fica preparado e só executa em PR do mesmo repositório quando `SONAR_TOKEN`, `SONAR_ORGANIZATION` e `SONAR_PROJECT_KEY` estiverem configurados. Falhas de uma análise iniciada não são mascaradas.
- WireMock 3.13.2 é adicionado somente ao escopo de teste para uso em commits futuros; nenhuma notificação é implementada aqui.
- Testcontainers 1.21.4 foi validado com Spring Boot 3.4.5; a propriedade fixa Docker `api.version=1.40` foi removida após validação local.
- A proteção de branch e os secrets/vars do GitHub são configurações remotas manuais, fora deste commit.

## Acceptance Criteria

1. PRs para `main` e `develop` executam checkout, Java 21 Temurin, cache Maven e `clean verify`.
2. O workflow tem somente permissão `contents: read`, usa `pull_request` e não expõe secrets a código de PR fork.
3. O Maven Wrapper é executável no runner antes da execução; Testcontainers executa PostgreSQL real e os 36 testes existentes passam.
4. JaCoCo produz relatórios XML e HTML, com cobertura de linhas, branches, classes e pacotes mensurável; os limites futuros não bloqueiam o build neste commit.
5. SonarCloud consome JaCoCo XML quando os identificadores e o secret estiverem configurados; sem configuração, Maven continua funcionando e a análise é explicitamente omitida. Falha real de análise configurada falha no step.
6. WireMock 3.13.2 tem escopo `test`; não há funcionalidades do Commit 05 ou posteriores.
7. Migration V1 e testes existentes são preservados; não há token, segredo ou identificador inventado versionado.
8. README, ADR, esta story e evidências descrevem configuração, resultados e limitações locais/remotas.

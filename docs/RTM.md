# Matriz de Rastreabilidade (RTM)

Esta é a matriz oficial de rastreabilidade do projeto. `RTM.md`, na raiz, é somente um encaminhamento de compatibilidade para este documento.

## Base das evidências e critérios de status

Os requisitos RF-01 a RF-14 abaixo vêm da especificação. Os riscos resumem o efeito de falha; as referências apontam testes ou artefatos localizáveis. “Verificado nos cenários cobertos” significa que os testes citados passaram, não que todos os comportamentos possíveis foram provados. “Parcial” indica evidência incompleta; “Pendente” indica que não há execução/evidência suficiente.

Em 2026-11-09, depois da integração dos PRs #2 (`87903e1`) e #1 (`8e5fb34`) em `develop`, a branch documental incorporou `origin/develop` no commit `d4b02bb`. Nessa revisão, `.\mvnw.cmd --batch-mode --no-transfer-progress clean verify` executou 202 testes, com 0 falhas, 0 erros e 0 ignorados; JaCoCo mediu 1.074/1.147 linhas (93,64%) e 220/280 branches (78,57%). O gate configurado (80%/70%) passou. Esses indicadores são de cobertura de código, não percentual de requisitos atendidos nem prova de ausência de vulnerabilidades.

O teste automatizado foi executado nesta branch após a integração. Os checks remotos de CI referem-se aos heads dos PRs #1 (`f37e958`) e #2 (`3705037`), e não a uma execução de CI do commit documental `d4b02bb`: [CI do PR #1](https://github.com/patrickassis7/Qas/actions/runs/42566300669) e [CI do PR #2](https://github.com/patrickassis7/Qas/actions/runs/42575378609).

## Limitações e status global

- **RF-13:** frontend implementado e integrado, mas falta matriz completa de validação visual nos seis tamanhos requeridos.
- **RF-14:** documentação existe; revisão final de README e alinhamento de contratos está planejada separadamente.
- **SonarCloud:** pendente; nenhuma análise ou Quality Gate é declarado.
- **Latência:** metas/SLO ainda não acordadas com o docente.
- **TDD/BDD:** evidência de processo ainda precisa de revisão consolidada.
- JaCoCo cobre execução de código pela suíte; não prova ausência de vulnerabilidades nem substitui teste visual, revisão de segurança ou análise estática.

Não se declara 100% de cobertura funcional nem aprovação global do projeto nesta matriz.
